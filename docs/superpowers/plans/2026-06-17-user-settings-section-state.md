# User Settings — Section State Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refactor the user settings section state architecture to remove `public_send` and string-interpolated dispatch, split the single PATCH route into two action routes (`expand` / `collapse`), and gut the `User::Settings` model and `User::Configurable` concern so the system is just a typed-column table plus a single explicit hash.

**Architecture:** One frozen `User::Settings::SECTION_COLUMNS` hash maps section name → boolean column symbol. `SECTIONS` is derived from its keys. The model is a 1-association wrapper with no methods. Two controller actions (`expand` / `collapse`) each look up the column from the hash and call `update!`. The `User::Configurable` concern is deleted; its 3 lines fold directly into `User`. The columns are renamed `*_open` → `*_expanded` to match the action verbs.

**Tech Stack:** Rails 8.1.2, Minitest, ActionController, ActiveRecord, Stimulus (`@rails/request.js` for POST), Propshaft/Importmap, AGENTS.md conventions (rubocop-rails-omakase, `==` not `===` in JS).

**Spec:** `docs/superpowers/specs/2026-06-17-user-settings-section-state-design.md`

- [ ] **Step 1: Replace the controller file**

Replace the contents of `app/javascript/controllers/section_controller.js` with:

```js
import { Controller } from "@hotwired/stimulus";
import { post } from "@rails/request.js";

export default class extends Controller {
  static values = {
    expandUrl: String,
    collapseUrl: String
  };

  connect() {
    this.onToggle = this.onToggle.bind(this);
    this.element.addEventListener("toggle", this.onToggle);
  }

  disconnect() {
    this.element.removeEventListener("toggle", this.onToggle);
  }

  showMore(event) {
    event.stopPropagation();
  }

  onToggle() {
    this.persist(this.element.open);
  }

  persist(open) {
    const url = open ? this.expandUrlValue : this.collapseUrlValue;
    if (!url) return;

    // @rails/request.js sets Content-Type to application/json unless the body
    // is a FormData. A plain URLSearchParams gets the wrong Content-Type and
    // Rails would try to JSON-parse it, so we use FormData to let the browser
    // set the correct multipart Content-Type and let Rails parse normally.
    const formData = new FormData();
    post(url, { body: formData }).catch(() => {});
  }
}
```

(Changes: `static values` now has `expandUrl` + `collapseUrl`; the `patch` import is replaced with `post`; `persist` selects the right URL based on the toggle state and POSTs an empty FormData.)
