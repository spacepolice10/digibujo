03 — Inbox

Inbox is part of the day — not part of the daylog.

Migrations bring last week's open tasks and parked ideas back for triage. Hooks and the browser extension add new candidates the same way. They propose. You decide.

daylog · untouched

Rewrite onboarding — parked note
Accept Skip
↻

Filter what still matters

Monthly plans that land on today, unfinished tasks from yesterday, and ideas you parked weeks ago — all surface here first. Accept what belongs in the daylog. Skip the rest.

Hooks

Inbound hooks take pushes from Zapier, bots, and other apps — and can go all the way to accepting email into bullets. Captures land in Pending. You decide what enters the day.

📦 DHL → ⚡ Zapier → ◉ Digibujo
Out for delivery → task “Be home 14:00–16:00” in Pending

Browser extension

Clip a page mid-scroll from Chrome or Firefox. It waits in the inbox window — never dumps into today.

06 — Self-host & stack

One command to your own server.

Pure Rails underneath — no platform, no managed database, no build pipeline. A small VPS, a domain, and kamal deploy.

deploy · your.server
# fresh VPS, nothing installed yet
$ kamal setup
✓docker installed · image built · app booted
✓TLS issued by Let's Encrypt, served by Thruster
# every release after that
$ kamal deploy
✓health-checked, swapped, zero downtime
rollback ready · previous image kept
$
1 server · 4 sqlite files · 0 add-ons

Kamal, not a platform

Docker over SSH to any box you rent. Deploys are health-checked and swapped in place; the previous image stays for an instant rollback.

kamal deploy kamal rollback kamal console kamal app logs -f

Pure Rails 8, no build step

Server-rendered ERB with Hotwire, Importmap, Propshaft, and modern CSS — no bundler. No Node, no node_modules, nothing to compile before boot.

SQLite for everything

Data, jobs, cache, and cable all live in SQLite — no Redis, no managed Postgres. A backup is a file copy. Solid Queue runs inside Puma, so one process is the whole backend.

O'Saasy — self-host for yourself, your family, or your team. Just don't resell it as a competing SaaS.
